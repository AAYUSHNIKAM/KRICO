# User Roles: Complete Role Architecture

---

## 1. Player

### Identity
A Player is an athlete (typically 8-25 years old) who uses SportsEco to find coaching, track performance, book venues, join challenges, and build a sports career portfolio.

### Goals
- Find the best coach for their sport and skill level
- Track and improve performance metrics over time
- Get video-based form analysis and feedback
- Discover and book nearby venues
- Participate in squad goals and community challenges
- Build a verifiable sports resume for scouts and academies

### Daily Workflow
1. Open dashboard to see today's schedule and upcoming sessions
2. Check performance metrics from recent training
3. Review AI video analysis feedback
4. Message coach for session adjustments
5. Book next session or venue
6. Log contribution to active squad goals
7. Browse community feed for motivation

### Pain Points
- Cannot find affordable, verified coaches nearby
- No centralized record of achievements or progress
- Training feels directionless without measurable goals
- Video analysis is expensive or unavailable
- Missed sessions due to poor scheduling visibility
- No motivation to train consistently without gamification

### Permissions
- Read own profile and performance data
- Update own player profile
- Book sessions with coaches
- Book venues
- Upload videos for AI analysis
- Create and join squad goals
- Post in community feed
- Chat with connected coaches
- View public coach and venue listings

### Features Available
- Player Dashboard (KPIs, sessions, performance, achievements)
- Video Analysis upload and review
- Squad Goals creation and participation
- Coach Discovery
- Venue Discovery and Booking
- Community Feed
- Achievement System
- Performance Tracking
- Session Calendar
- Chat

### KPIs
- Sessions attended per week/month
- Performance score improvement over time
- Number of achievements unlocked
- Coach rating given
- Squad goals completed
- Video analyses uploaded
- Community engagement score

### Revenue Opportunities
- Freemium model: Basic tracking free, premium analytics subscription
- Per-session booking fees (small platform fee)
- In-app purchases: custom training plans, exclusive content
- Tournament entry fees

## 2. Coach

### Identity
A Coach is a sports trainer (independent or academy-affiliated) who uses SportsEco to find students, manage sessions, grow reputation, and build a sustainable coaching business.

### Goals
- Find and retain students consistently
- Manage scheduling, payments, and contracts efficiently
- Build verifiable reputation through ratings and reviews
- Increase income through subscriptions, milestones, and placements
- Access performance data to tailor coaching
- Get placed at reputable academies

### Daily Workflow
1. Dashboard overview: today's sessions, earnings, new requests
2. Approve/reject session bookings
3. Take attendance for completed sessions
4. Log session notes and player observations
5. Review video analysis submitted by players and provide feedback
6. Manage milestones on career timeline
7. Check subscription status and manage plan
8. Browse academy job listings and apply
9. Respond to chat messages

### Pain Points
- Irregular income with no subscription base
- No platform to build reputation outside word-of-mouth
- Manual scheduling leads to double-booking and confusion
- Students cancel last minute with no penalty
- No way to showcase coaching philosophy, credentials, or results
- Difficult to transition to academy coaching roles
- No data-driven insights to improve coaching methods

### Permissions
- Create and manage own coach profile
- Set hourly rates and availability
- Create and manage sessions
- Accept/reject booking requests
- View student profiles and performance
- Provide video analysis feedback
- Manage career milestones
- Post job applications to academies
- View and manage contracts
- Message connected players
- Manage subscription tier

### Features Available
- Coach Dashboard (stats, sessions, milestones, subscription)
- Session Management (create, reschedule, cancel)
- Student Management (view, message, track progress)
- Earnings Dashboard (monthly, total, per-session)
- Career Milestones
- Video Analysis Review
- Academy Job Board
- Coach Invitations from Academies
- Contract Management
- Subscription Management (Starter/Professional/Elite)
- Chat

### KPIs
- Total sessions completed
- Active students count
- Average rating and review score
- Monthly/quarterly earnings
- Student retention rate
- Milestones achieved
- Academy placement status
- Session completion rate (vs cancellations)

### Revenue Opportunities
- Subscription tiers (Starter free, Professional Rs.499/mo, Elite Rs.999/mo)
- Platform commission on session bookings (10%)
- Featured coach listings (paid promotion)
- Premium analytics and insights
- Academy placement fee
- Training program sales

## 3. Academy

### Identity
An Academy is a sports training organization that uses SportsEco to manage batches, hire coaches, market programs, and run operations digitally.

### Goals
- Digitize batch management and student enrollment
- Find, hire, and retain quality coaches
- Market programs and camps to the right audience
- Track coach performance and student outcomes
- Build academy brand and reputation
- Increase enrollment and student retention

### Daily Workflow
1. Dashboard: batch occupancy, active coaches, new enrollments
2. Review coach applications and send invitations
3. Create and manage batches (capacity, schedule, sport)
4. Assign coaches to batches
5. Post coaching job listings
6. Create advertising campaigns
7. Review academy placements
8. Message coaches and parents
9. View analytics and reports

### Pain Points
- Manual paper-based batch and attendance management
- No centralized coach hiring and evaluation system
- Marketing is expensive and untargeted
- Cannot demonstrate academy quality to prospective parents
- No tools to track student progress at scale
- Coaches leave without notice, disrupting operations
- No competitive intelligence on other academies

### Permissions
- Manage academy profile and branding
- Create, update, delete batches
- Assign coaches to batches
- Invite coaches
- Post and manage job listings
- Create advertising campaigns
- View coach applications
- Manage placements
- Message coaches and parents
- View analytics

### Features Available
- Academy Dashboard (stats, batches, placements)
- Batch Management (create, capacity tracking, assign coaches)
- Coach Management (invite, assign, track)
- Job Board (post, manage applications)
- Advertising Suite (campaign creation, budget management)
- Placement Tracking
- Coach Invitation System
- Chat
- Analytics

### KPIs
- Total enrolled students
- Active batches and capacity utilization
- Number of active coaches
- Coach placements (outgoing)
- Campaign ROI
- Student retention rate
- Academy reputation score
- Coach satisfaction score

### Revenue Opportunities
- Academy subscription (monthly/yearly)
- Featured academy listings
- Advertising campaign spend
- Coach placement commission
- White-label academy portal
- Bulk student enrollment discount

## 4. Venue Partner

### Identity
A Venue Partner is a sports facility owner or manager who lists venues on SportsEco for booking by players, coaches, and academies.

### Goals
- Maximize venue utilization across all time slots
- Simplify booking and payment management
- Build venue reputation through ratings
- Attract more bookings through platform visibility

### Daily Workflow
1. Check booking requests for today
2. Approve/decline bookings
3. Update venue availability
4. Manage venue profile and photos
5. Respond to reviews
6. View utilization reports

### Pain Points
- Courts/grounds idle during non-peak hours
- Manual booking process is administrative burden
- No dynamic pricing to incentivize off-peak usage
- Difficulty attracting new customers
- No insight into booking patterns or popular sports

### Permissions
- Create and manage venue profile
- Set pricing and availability
- Approve/decline bookings
- Respond to reviews
- View booking analytics
- Update amenities and photos

### Features Available
- Venue Profile Management
- Booking Calendar
- Booking Approval Flow
- Reviews and Ratings
- Utilization Analytics
- Dynamic Pricing (future)

### KPIs
- Monthly booking count
- Capacity utilization rate (%)
- Average rating
- Repeat booking rate
- Revenue per venue
- Peak vs off-peak utilization ratio

### Revenue Opportunities
- Commission on each booking (10-15%)
- Featured venue listing
- Promotional campaigns
- Premium analytics subscription
- Multi-venue management tier

## 5. Parent

### Identity
A Parent is a guardian (30-50 years old) who manages one or more child athletes' sports journey through SportsEco.

### Goals
- Monitor child's training progress and attendance
- Track performance metrics and improvement
- Find and vet quality coaches
- Manage coaching payments and schedules
- Receive AI-generated progress reports

### Daily Workflow
1. Dashboard: view child's upcoming sessions
2. Review coach ratings and session history
3. Log performance metrics (speed, accuracy, etc.)
4. View progress reports and analytics
5. Book coaches or venues for child
6. Message coaches
7. Review billing and payment history

### Pain Points
- No visibility into what happens during coaching sessions
- Cannot objectively measure child's improvement
- Hard to verify coach credentials and track record
- Coordinating multiple children's schedules is chaotic
- No consolidated view of expenses across coaches and venues
- Limited ability to support training at home

### Permissions
- View linked players' profiles and data
- Book sessions on behalf of players
- Log performance metrics for players
- View coach profiles and ratings
- Message coaches
- View payment history
- Receive progress notifications

### Features Available
- Parent Dashboard (multi-player overview)
- Player Progress Tracking
- Performance Metric Logging
- Coach Discovery (read-only booking)
- Session Management
- Payment History
- Reports and Analytics

### KPIs
- Children's session attendance rate
- Performance improvement trends
- Coach rating accuracy
- Platform engagement (logins per week)
- Session booking frequency

### Revenue Opportunities
- Parent subscription (premium reports)
- Multi-player discount packages
- Exclusive parent webinars and content
- Sports gear and equipment marketplace access

## 6. Admin

### Identity
An Admin is a SportsEco platform operator responsible for managing users, venues, coupons, tasks, and overall platform health.

### Goals
- Maintain platform integrity and quality
- Manage venue listings and verification
- Release promotional coupons and offers
- Monitor platform growth metrics
- Handle administrative tasks and escalations

### Daily Workflow
1. Dashboard: overview of platform health (users, venues, revenue, active users)
2. Review and approve venue additions
3. Manage coupon campaigns
4. Review reported content or users
5. Manage admin tasks
6. Monitor revenue and growth metrics

### Pain Points
- No centralized admin panel earlier (had to use Firebase console)
- Manual venue verification process
- Limited visibility into platform-wide trends
- No way to offer promotions without engineering support
- Task management across team is fragmented

### Permissions
- View all users across all roles
- Create, update, delete venues
- Create and manage coupons
- Create admin tasks
- View platform revenue
- View analytics
- Manage any report/flag

### Features Available
- Admin Dashboard (users, venues, revenue, active users, tasks)
- Venue Management (add, verify, edit)
- Coupon Management (create, activate/deactivate)
- Task Management (create, prioritize, track)
- User Overview (all users list)
- Revenue Tracking

### KPIs
- Total registered users
- Active users (30-day)
- Total venues and verified venues
- Active coupons and redemption rate
- Total platform revenue
- Task completion rate
- Platform GMV

### Revenue Opportunities
- Admin is cost center (platform operations)
- Efficiency gains through automation reduce operational cost

## Role Hierarchy & Relationships

```
Admin
  |
  +-- Controls platform, manages all roles
  |
  +-- Academy
  |     |
  |     +-- Hires Coach (via invitations/jobs)
  |     +-- Enrolls Player (via batches)
  |     +-- Books Venue
  |
  +-- Coach
  |     |
  |     +-- Trains Player (via sessions)
  |     +-- Works at Academy (via placement)
  |     +-- Books Venue (for sessions)
  |
  +-- Player
  |     |
  |     +-- Links to Parent
  |     +-- Learns from Coach
  |     +-- Attends Academy
  |     +-- Books Venue
  |
  +-- Parent
  |     |
  |     +-- Manages Player(s)
  |     +-- Books on behalf
  |
  +-- Venue Partner
        |
        +-- Hosts Sessions for all roles
```

## Cross-Role Interactions

| Interaction | Roles Involved | Via Feature |
|---|---|---|
| Book Session | Player -> Coach | Session Booking |
| Hire Coach | Academy -> Coach | Invitations/Jobs |
| Form Analysis | Player -> Coach | Video Analysis |
| Squad Goal | Player <-> Player | Squad Goals |
| Messaging | Any <-> Any | Chat |
| Contract | Player/Coach/Academy | Contract System |
| Review | Player -> Coach/Venue | Rating System |
| Track Progress | Parent -> Player | Parent Dashboard |
| Venue Booking | Any -> Venue | Venue Booking |
